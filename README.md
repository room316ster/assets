เว็บแอปพลิเคชันบริหารจัดการและตรวจนับครุภัณฑ์ประจำปี พัฒนาขึ้นเพื่อเพิ่มประสิทธิภาพและความถูกต้องในการสำรวจพัสดุของหน่วยงาน รองรับการสแกนผ่านกล้องมือถือ การทำงานแบบออฟไลน์ ติดตั้งใช้งานแบบแอปพลิเคชันบนสมาร์ตโฟน (PWA) พร้อมระบบแจ้งเตือนผ่าน Telegram อัตโนมัติ

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. 📲 ใช้งานได้เหมือนแอปพลิเคชันจริง (Progressive Web App - PWA)
- รองรับการกด **"บันทึกแอปลงหน้าจอมือถือ"** (Add to Home Screen) ทั้งบน **Android** และ **iOS (iPhone/iPad)**
- ใช้งานได้เต็มหน้าจอแบบ Standalone ไม่มีแถบ URL Bar
- **PWA Auto-Update:** ระบบตรวจจับเวอร์ชันใหม่อัตโนมัติ แจ้งเตือนผู้ใช้งานให้อัปเดตเป็นเวอร์ชันล่าสุดได้ทันที

### 2. ⚡ สแกนตรวจนับพัสดุผ่านกล้องมือถือ (Smart QR Scanner)
- **เสียง "ตี๊ด" (Beep Audio) และสั่นเตือน (Haptic Vibration):** แจ้งเตือนทันทีที่สแกนสำเร็จ ไม่ต้องคอยก้มมองหน้าจอ
- **สลับกล้องได้อิสระ (Camera Switcher):** รองรับมือถือที่มีกล้องหลายเลนส์
- **เปิด-ปิดไฟฉาย (Flashlight Toggle):** สแกนได้ง่ายแม้ในห้องพัสดุที่แสงน้อย หรือส่องใต้โต๊ะ
- **ถ่ายภาพสแกนทดแทน (Photo Fallback):** หากกล้องมีปัญหาสามารถถ่ายรูปเพื่ออ่าน QR Code ได้

### 3. 🏢 ติดตามความคืบหน้ารายห้อง (Location Audit Tracker)
- แสดงสรุปเปอร์เซ็นต์ความคืบหน้าการตรวจนับแยกตามห้อง/สถานที่ตั้งบนหน้าแดชบอร์ด
- แถบ Progress Bar พร้อมสถานะตรวจแล้ว / ทั้งหมด
- คลิกที่ชื่อห้องเพื่อ **กระโดดไปยังรายการพัสดุของห้องนั้นทันที**

### 4. 📸 ประทับลายน้ำและวันเวลาลงบนรูปถ่ายอัตโนมัติ (Photo Watermark & Timestamp)
- ทำการประทับแถบลายน้ำลงบนภาพถ่ายโดยตรงผ่าน Canvas ก่อนอัปโหลด
- แสดงข้อมูล: `รหัสพัสดุ | วันที่และเวลาที่บันทึก | ผู้ตรวจสอบ/ลงทะเบียน | ศาลแขวงอุบลราชธานี`
- ป้องกันการใช้ภาพซ้ำ และเป็นหลักฐานทางราชการที่น่าเชื่อถือ

### 5. 🔔 แจ้งเตือนเรียลไทม์ผ่าน Telegram (Telegram Bot Notifications)
- เชื่อมต่อผ่าน **Telegram Bot API** รองรับทั้งส่งเข้าแชตส่วนตัวหรือกลุ่มงานพัสดุ
- เลือกเปิด/ปิดเหตุการณ์ที่ต้องการแจ้งเตือนได้ในเมนูตั้งค่า:
  - 🔍 เมื่อมีการตรวจนับสภาพพัสดุประจำปี
  - 🔧 เมื่อมีการส่งซ่อม / อัปเดตสถานะงานซ่อมบำรุง
  - 🤝 เมื่อมีการยืม-คืนพัสดุ
- มีปุ่ม **"ทดสอบส่งข้อความ"** ในหน้าตั้งค่าเพื่อตรวจสอบการเชื่อมต่อทันที

### 6. 📊 ส่งออกไฟล์ Excel (.xlsx) และ CSV (UTF-8 BOM ภาษาไทยไม่เพี้ยน)
- ส่งออกไฟล์ **Excel (.xlsx แท้)** ผ่าน SheetJS พร้อมจัดฟอร์แมตข้อมูลเรียบร้อย
- ส่งออกไฟล์ **CSV พร้อมใส่ UTF-8 BOM (`\uFEFF`)** เปิดใน Microsoft Excel บน Windows ได้ภาษาไทยถูกต้อง 100% ไม่เป็นภาษาต่างดาว

### 7. 🎤 ค้นหาพัสดุด้วยเสียงภาษาไทย (Thai Voice Search)
- ค้นหารหัสพัสดุ ชื่อรายการ ยี่ห้อ หรือสถานที่ตั้ง เพียงแตะที่ปุ่มไมโครโฟนแล้วพูด
- รองรับ Web Speech API ภาษาไทย (`th-TH`) พร้อมไฟสถานะกระพริบขณะกำลังบันทึกเสียง

### 8. 📶 รองรับการทำงานแบบออฟไลน์ (Offline Mode)
- เดินตรวจนับในจุดที่ไม่มีสัญญาณอินเทอร์เน็ตได้ ข้อมูลจะถูกบันทึกไว้ในเครื่อง
- ระบบจะทำการ **ซิงค์ข้อมูลเข้า Google Sheets อัตโนมัติ** ทันทีที่เชื่อมต่ออินเทอร์เน็ต

### 9. 🖼️ ย่อขนาดรูปภาพอัจฉริยะ (Client-side Image Compression)
- ระบบบีบอัดรูปถ่ายจากกล้องมือถือผ่าน HTML5 Canvas อัตโนมัติ
- **ลดขนาดไฟล์จาก 5–12 MB เหลือเพียง 150–250 KB** (ประหยัดพื้นที่กว่า 95%) อัปโหลดเร็ว ไม่ติดขีดจำกัด Google Drive

### 10. 🖨️ พิมพ์ป้าย QR Code และรายงานราชการ
- **พิมพ์ป้าย QR Code 2 รูปแบบ:**
  - *ป้ายเดี่ยว (50x20 mm):* สำหรับเครื่องพิมพ์ความร้อน (Thermal Label Printer)
  - *กระดาษ A4 รวม (ตาราง 24 ดวง/แผ่น):* สำหรับพิมพ์ลงกระดาษสติกเกอร์ A4
- **รายงานสรุปเสนอผู้บริหาร (PDF & Excel):**
  - กรองข้อมูลตามสภาพพัสดุ และกรองแยกตาม **สถานที่ตั้ง/ห้อง** ได้
  - สร้างเอกสารแบบฟอร์มราชการพร้อมช่องลงนามสำหรับเจ้าหน้าที่พัสดุและผู้อำนวยการฯ

### 11. 🤝 ระบบยืม-คืนพัสดุ & ติดตามงานแจ้งซ่อม (Borrow & Maintenance)
- สแกนเพื่อทำรายการยืม-คืน ระบุชื่อผู้ยืมและตรวจสอบสถานะได้ทันที
- กระดานติดตามงานซ่อมบำรุง ปรับสถานะ (ส่งซ่อม / กำลังซ่อม / ซ่อมเสร็จแล้ว)

### 12. 🛡️ ความปลอดภัยและการจัดการสิทธิ์ (Security & Audit)
- เข้ารหัสผ่านด้วยมาตรฐาน **SHA-256** (พร้อมระบบ Backward Compatible)
- **ระบบรออนุมัติสมาชิกใหม่จาก Admin (Approval Workflow):** สมาชิกที่ลงทะเบียนใหม่จะมีสถานะเป็น "รออนุมัติ" (Pending) โดยอัตโนมัติ และไม่สามารถเข้าสู่ระบบได้จนกว่าผู้ดูแลระบบ (Admin) จะกดอนุมัติ
- **ระบบแจ้งเตือนแอดมินทาง Telegram ทันที:** เมื่อมีผู้ใช้ลงทะเบียนใหม่ ระบบจะส่งการแจ้งเตือนพร้อมชื่อและ Username เข้ากลุ่ม/แชต Telegram ของแอดมินแบบเรียลไทม์
- **ส่งอีเมลแจ้งผู้ใช้เมื่อได้รับการอนุมัติ:** เมื่อแอดมินกดอนุมัติสิทธิ์ ระบบจะส่งอีเมลแจ้งเตือนไปยังผู้ใช้โดยอัตโนมัติ
- **แดชบอร์ดจัดการผู้ใช้งาน (User Management Dashboard):** แอดมินสามารถกรองดูรายชื่อผู้ใช้แยกตามสถานะ (รออนุมัติ, อนุมัติแล้ว, ระงับใช้งาน), ค้นหารายชื่อ, ปรับเปลี่ยนสิทธิ์ Admin/User, สั่งระงับ/ปลดระงับการใช้งาน หรือลบบัญชีผู้ใช้
- **ป้ายแจ้งเตือนสมาชิกใหม่ (Pending Badge):** แสดงจำนวนผู้ใช้ที่รออนุมัติบนเมนูด้านข้างแบบเคลื่อนไหว (Pulsing Badge) ทันที
- ระบบบันทึกประวัติการใช้งานอย่างละเอียด (**Audit Logs**)
- แอดมินสามารถสุ่มรีเซ็ตรหัสผ่านและส่งอีเมลแจ้งเตือนผู้ใช้ได้อัตโนมัติ

### 13. 📦 สำรองข้อมูลอัตโนมัติเมื่อสิ้นสุดรอบ & ดาวน์โหลดข้อมูลย้อนหลัง (Auto-Backup & Archive)
- **สำเนาฐานข้อมูลอัตโนมัติ:** เมื่อแอดมินเปลี่ยนชื่อรอบการตรวจสอบ (เช่น ขึ้นปีงบประมาณใหม่) ระบบจะคัดลอก Spreadsheet ทั้งไฟล์ของรอบเดิมเก็บไว้ใน Google Drive ให้อัตโนมัติทันที
- **หน้าต่างข้อมูลย้อนหลัง:** เรียกดูประวัติการสำรองข้อมูลแต่ละรอบปี สามารถกด **ดาวน์โหลดไฟล์ Excel (.xlsx)** ตรง หรือ **เปิดดู Google Sheets** ได้ตลอดเวลา
- **สำรองข้อมูลด้วยตนเอง:** มีปุ่มกดสำรองข้อมูล ณ ขณะนั้นได้ทันทีโดยไม่ต้องรอเปลี่ยนรอบ

### 14. 🏛️ ปรับแต่งชื่อหน่วยงาน/องค์กรได้อิสระ (Custom Organization Name)
- กำหนดหรือแก้ไขชื่อหน่วยงาน/องค์กรได้โดยตรงผ่านเมนู **"ตั้งค่าระบบ" (Settings)**
- ระบบจะอัปเดตชื่อหน่วยงานให้อัตโนมัติทุกจุด: หัวเว็บไซต์, แถบเมนูด้านข้าง, หน้าสมัครสมาชิก, หน้ารายงานราชการ (PDF/Excel), ป้ายพิมพ์ QR Code, ลายน้ำบนรูปถ่าย และข้อความแจ้งเตือน Telegram

### 15. ⚡ โหมดสแกนด่วนต่อเนื่อง (Continuous Scan Mode) *(ใหม่ v6.0!)*
- **สแกนยิงรัวๆ ติดกันในห้องเดิม:** ตรวจนับพัสดุในห้องเดียวกันได้รวดเร็วต่อเนื่องโดยไม่ต้องสลับหน้าจอหรือกดยืนยันทีละชิ้น
- **บันทึกสภาพ "ปกติ" อัตโนมัติทันที:** เมื่อกล้องจับ QR Code ระบบจะบันทึกผลว่าตรวจพบแล้วในสภาพปกติ พร้อมระบุสถานที่และผู้ตรวจสอบให้อัตโนมัติ
- **ป้องกันการยิงซ้ำ (Scan Throttling):** มีระบบหน่วงเวลา 2.2 วินาที และจดจำรายการล่าสุดเพื่อป้องกันการบันทึกซ้ำซ้อน
- **แถบแสดงสถิติบนกล้องแบบเรียลไทม์:** แสดงยอดรวมที่สแกนสำเร็จในรอบนั้น พร้อมเสียง "ตี๊ด 2 ครั้ง" และการสั่นเตือนเพื่อความมั่นใจ

### 16. 🔍 ตัวกรองพัสดุที่ยังไม่ได้ตรวจนับในห้องนี้ (Uninspected Filter) *(ใหม่ v6.0!)*
- **ปุ่มด่วน "🔴 ยังไม่ตรวจ (X ชิ้น)":** บนการ์ดห้องในหน้า Dashboard สามารถกดดูเฉพาะรายการพัสดุที่ยังค้างการตรวจนับในรอบปัจจุบันได้ทันที
- **ปุ่มทางลัด "⚡ ตรวจห้องนี้":** สลับเข้าสู่โหมดสแกนและล็อกห้องนั้นให้อัตโนมัติ ไม่ต้องเลือกห้องใหม่
- **ฟิลเตอร์ Uninspected ในหน้าตารางพัสดุ:** กรองแสดงเฉพาะชิ้นที่ตกสำรวจ ทำให้เจ้าหน้าที่ไม่พลาดการตรวจนับแม้แต่ชิ้นเดียว

### 17. 🚀 แคชเซิร์ฟเวอร์ด้วย CacheService (Server-Side Cache) *(ใหม่ v6.0!)*
- **เร่งความเร็วการโหลดข้อมูล 3–5 เท่า:** แคชข้อมูลรวมบน Google Apps Script (`CacheService.getScriptCache()`) ด้วยระบบแบ่งชิ้นส่วน (Chunking) รองรับฐานข้อมูลขนาดใหญ่
- **ล้างแคชอัตโนมัติ (Auto Invalidation):** ระบบจะเคลียร์แคชทันทีที่มีการบันทึกตรวจนับ แก้ไขพัสดุ หรือทำรายการยืม-คืน ข้อมูลจึงสดใหม่อยู่เสมอ
- **ปุ่มล้างแคชด้วยตนเอง (Manual Purge):** สำหรับ Admin ในหน้าตั้งค่าระบบ กรณีมีการเข้าไปแก้ไขข้อมูลใน Google Sheets โดยตรง

### 18. 📜 แบบฟอร์มรายงานผลการตรวจสอบพัสดุประจำปีตามระเบียบราชการ (ข้อ 213) *(ใหม่ v6.0!)*
- **ถูกต้องตามระเบียบกระทรวงการคลังฯ พ.ศ. 2560 ข้อ 213:** รูปแบบบันทึกข้อความราชการมาตรฐาน พร้อมตราครุฑและระยะขอบกระดาษราชการ
- **ตารางสถิติผลการสำรวจ 5 สถานะ:** สรุปยอดสภาพปกติ, ชำรุดซ่อมได้, ชำรุดซ่อมไม่ได้, เสื่อมสภาพ/ไม่จำเป็น, และสูญหาย/หาไม่พบ
- **ช่องลงนามคณะกรรมการตรวจสอบพัสดุ 3 ท่าน:** ประธานกรรมการ และกรรมการ 2 ท่าน พร้อมช่องลงนามความเห็นของหัวหน้าหน่วยงานของรัฐ
- **บันทึกรายชื่อกรรมการอัตโนมัติ:** ระบบจำรายชื่อและตำแหน่งของกรรมการไว้ในเครื่อง ไม่ต้องพิมพ์ซ้ำทุกครั้งที่ออกรายงาน

### 19. ⏰ ฟังก์ชันรายงานสรุปประจำวันอัตโนมัติทาง Telegram (Daily Digest) *(ใหม่ v6.0!)*
- **ส่งยอดสรุปประจำวันเข้า Telegram ตอนเย็น (17.00 น.):** สรุปยอดรวมที่ตรวจนับได้ในวันนั้น รายงานความคืบหน้ารวมของทั้งรอบ (%) จำแนกตามสภาพ และจัดอันดับเจ้าหน้าที่ผู้ตรวจนับสูงสุด
- **ระบบ Time-Driven Trigger อัตโนมัติ:** สร้างและบริหารจัดการ Trigger บน Google Apps Script ได้โดยตรงจากหน้าตั้งค่าระบบ
- **ปุ่ม "ส่งรายงานสรุปประจำวันทันที":** กดเพื่อทดสอบส่งสรุปยอดประจำวันเข้า Telegram ได้ทันทีโดยไม่ต้องรอถึงเวลาเย็น

## 📖 คู่มือการใช้งานฟีเจอร์ใหม่ v6.0 (New Features Guide)

### 1. ⚡ โหมดสแกนด่วนต่อเนื่อง (Continuous Scan Mode)
เหมาะอย่างยิ่งสำหรับการเดินตรวจนับในห้องที่มีพัสดุจำนวนมากและตั้งอยู่ในห้องเดียวกัน:
1. ไปที่เมนู **"สแกน QR Code"**
2. เลือก **สถานที่ตั้ง/ห้องปัจจุบัน** ที่กำลังตรวจนับ
3. กดปุ่มสีเขียว **"⚡ สแกนด่วนต่อเนื่อง (ยิงรัวๆ)"** หรือเปิดสวิตช์โหมดสแกนต่อเนื่อง
4. ส่องกล้องไปที่ป้าย QR Code ของพัสดุทีละชิ้น:
   - กล้องจะตรวจจับและบันทึกผลว่า **"ปกติ"** ให้อัตโนมัติทันที
   - มีเสียงแจ้งเตือนและสั่นตอบรับ (Haptic) 
   - แถบด้านบนของกล้องจะแสดงจำนวนชิ้นที่สแกนสำเร็จแบบเรียลไทม์ (เช่น `สแกนสำเร็จ 5 ชิ้น`)
   - ระบบมีระบบหน่วงเวลา 2.2 วินาที ป้องกันการยิงซ้ำชิ้นเดิม
5. เมื่อตรวจเสร็จ ให้แตะปุ่ม **"ปิดกล้อง"** ผลการตรวจนับทั้งหมดจะได้รับการบันทึกเรียบร้อย

### 2. 🔍 ตัวกรองพัสดุที่ยังไม่ได้ตรวจนับในห้องนี้ (Uninspected Filter)
ช่วยให้ทราบทันทีว่าในห้องนั้นๆ เหลือพัสดุชิ้นใดบ้างที่ยังไม่ได้ตรวจนับในรอบปัจจุบัน:
- **วิธีที่ 1 (จากหน้าแดชบอร์ด):** ที่การ์ดติดตามรายห้อง ให้กดปุ่ม **"🔴 ยังไม่ตรวจ (X ชิ้น)"** ระบบจะพาไปยังหน้าตารางพัสดุและกรองแสดงเฉพาะรายการที่ยังค้างตรวจในห้องนั้นทันที
- **วิธีที่ 2 (จากหน้าตารางพัสดุ):** เลือกห้องที่ต้องการในช่องเลือกห้อง แล้วคลิกปุ่มตัวกรอง **"🔴 ยังไม่ตรวจนับ"**
- **ทางลัดตรวจทันที:** กดปุ่ม **"⚡ ตรวจห้องนี้"** บนการ์ดห้อง เพื่อเปิดกล้องเข้าสู่โหมดสแกนโดยล็อกห้องนั้นไว้ให้อัตโนมัติ

### 3. 🚀 แคชเซิร์ฟเวอร์ด้วย CacheService (Server-Side Cache)
เร่งสปีดการดึงข้อมูลบน Google Apps Script ให้โหลดหน้าเว็บได้รวดเร็วทันใจ:
- ข้อมูลพัสดุทั้งหมดจะถูกเก็บในแคชเซิร์ฟเวอร์เป็นเวลา 5 นาที (TTL 300s)
- เมื่อมีการบันทึกตรวจนับ แก้ไขพัสดุ หรือทำรายการยืม-คืน ระบบจะ **ล้างแคชให้อัตโนมัติ (Auto-Invalidate)** ทันที เพื่อให้ข้อมูลเป็นปัจจุบัน
- **กรณีแก้ไขข้อมูลบน Google Sheets โดยตรง:** แอดมินสามารถไปที่เมนู **"ตั้งค่าระบบ" > "แคชเซิร์ฟเวอร์ (CacheService)"** แล้วกดปุ่ม **"ล้างแคชเซิร์ฟเวอร์ทันที"** เพื่อบังคับให้เซิร์ฟเวอร์โหลดข้อมูลสดใหม่จากชีตได้ทันที

### 4. 📜 แบบฟอร์มรายงานผลการตรวจสอบพัสดุประจำปีตามระเบียบราชการ (ข้อ 213)
สร้างเอกสารบันทึกข้อความราชการตามระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 ข้อ 213:
1. เข้าไปที่เมนู **"รายงานราชการ (ข้อ 213)"** จากแถบเมนูด้านข้าง
2. ระบบจะคำนวณสถิติผลการตรวจนับ 5 สภาพให้อัตโนมัติ:
   - พัสดุสภาพปกติ (ใช้การได้)
   - พัสดุชำรุด (ซ่อมแซมได้)
   - พัสดุชำรุด (ซ่อมแซมไม่ได้/ไม่คุ้มค่า)
   - พัสดุเสื่อมสภาพ / ไม่จำเป็นต้องใช้ในราชการต่อไป
   - พัสดุสูญหาย / หาตัวไม่พบ
3. กรอกข้อมูลส่วนหัวและรายชื่อคณะกรรมการ:
   - เลขที่บันทึกข้อความ และวันที่รายงาน
   - ประธานกรรมการตรวจสอบพัสดุ (ชื่อและตำแหน่ง)
   - กรรมการตรวจสอบพัสดุ 2 ท่าน (ชื่อและตำแหน่ง)
   - ชื่อและตำแหน่งของหัวหน้าหน่วยงานของรัฐ / ผู้อำนวยการฯ
   *(ระบบจะจดจำรายชื่อและตำแหน่งไว้ในเครื่อง ไม่ต้องพิมพ์ใหม่ในครั้งต่อไป)*
4. กดปุ่ม **"พิมพ์รายงาน / บันทึกเป็น PDF"** เพื่อสั่งพิมพ์ลงกระดาษ A4 หรือบันทึกเป็น PDF ที่สวยงาม ถูกต้องตามระเบียบงานสารบรรณ

### 5. ⏰ ฟังก์ชันรายงานสรุปประจำวันอัตโนมัติทาง Telegram (Daily Digest)
ส่งสรุปยอดผลการปฏิบัติงานตรวจนับประจำวันเข้า Telegram ทุกเย็น เวลา 17.00 น.:
1. เข้าสู่ระบบด้วยสิทธิ์ **Admin** ไปที่เมนู **"ตั้งค่าระบบ"**
2. ตรวจสอบว่าได้ตั้งค่า Telegram Bot Token และ Chat ID เรียบร้อยแล้ว
3. ในส่วน **"การแจ้งเตือน Telegram"** ให้กดปุ่ม **"⏰ ตั้งเวลาส่งอัตโนมัติ (Trigger)"**
4. ยืนยันการตั้งเวลา ระบบจะสร้าง Time-Driven Trigger บน Google Apps Script ให้ส่งข้อความสรุปทุกวันเวลาประมาณ 17.00 – 18.00 น.
5. สามารถกดปุ่ม **"ส่งรายงานสรุปประจำวันทันที"** เพื่อทดสอบดูรูปแบบข้อความสรุปยอดประจำวันได้ทันที
